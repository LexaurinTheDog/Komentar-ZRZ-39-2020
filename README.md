# Komentář k zákonu č. 39/2020 Sb., o realitním zprostředkování a o změně souvisejících zákonů (zákon o realitním zprostředkování)

Otevřený komentář k zákonu o realitním zprostředkování — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; povinnosti realitního zprostředkovatele, bezúhonnost a pojištění, smlouva o realitním zprostředkování, zakázaná ujednání, výhradní zprostředkování, provize, kontrola a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2020-00039_2021-07-01`.
